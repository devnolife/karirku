Persiapan Vibecoding (Sesi 2)

AI diperbolehkan — tapi yang dinilai adalah PEMAHAMAN & TESTING-mu. Latih alur ini sampai jadi refleks.

🔄Workflow AI SDLC (ucapkan saat ngoding)

  • 1. Clarify — ulangi requirement & sebut asumsi.
  • 2. Plan — pecah jadi fungsi kecil; sebut input/output.
  • 3. Prompt — minta 1 fungsi spesifik, bukan "buatkan semua".
  • 4. Review — baca tiap baris, sesuaikan dengan spec.
  • 5. Test — test case: normal, edge, invalid.
  • 6. Explain — jelaskan Big-O & alasan pendekatan.

💬Kalimat Penyelamat (saat ditanya)

  • "Fungsi ini O(n) karena saya iterasi list sekali pakai hashmap."
  • "Saya pilih dict untuk lookup O(1) dibanding list O(n)."
  • "Edge case: input kosong, duplikat, dan None."
  • "Verifikasi: 3 test — typical, boundary, invalid."
  • "Kalau scale besar, saya ganti ke generator agar hemat memori."

🧪Template Test Cepat (Python)

def solve(x):
    return x * 2

# test: normal / edge / invalid
assert solve(3) == 6
assert solve(0) == 0
assert solve(-2) == -4
print("semua test lulus ✓")

⚠️Jebakan yang Harus Dihindari

  • Copy-paste AI tanpa baca → ketahuan saat ditanya.
  • Diam saat ngoding → mereka mau dengar reasoning.
  • Lupa testing → nilai "testing" hilang.
  • Over-engineering → kerjakan yang diminta, simpel & jalan dulu.
